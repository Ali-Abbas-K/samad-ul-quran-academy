Bundled web fonts
=================

These files are self-hosted so the site loads no third-party resources (the
Content-Security-Policy sets font-src 'self') and so the Android build works
without network access to a font CDN.

  playfair-display-latin.woff2      Playfair Display  - SIL Open Font License 1.1
  playfair-display-latin-ext.woff2  Playfair Display  - SIL Open Font License 1.1
  manrope-latin.woff2               Manrope           - SIL Open Font License 1.1
  amiri-arabic.woff2                Amiri             - SIL Open Font License 1.1

All four are licensed under the SIL Open Font License, Version 1.1, which
permits bundling and redistribution with this website and inside the Android
